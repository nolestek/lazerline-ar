# Hoop Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Hoop drill: a virtual swing-plane hoop locked to the golfer's address, green/red by whether the clubhead stays in its plane, with a haptic buzz when it leaves during a swing.

**Architecture:** Pure hoop math (plane from address pose, distance, classification, address predicate) goes in a new Node-tested module `src/hoop.js`. `src/settings.js` gains a `drill` field. `src/view.js` gains a hoop ring and a 3D clubhead trail. `src/main.js` gains three hoop-setup states and a drill branch in `ready`. Line drill is unchanged.

**Tech Stack:** Vanilla JS ES modules, three.js 0.170.0 (CDN import map), WebXR `immersive-ar`, Node built-in test runner.

**Spec:** `docs/superpowers/specs/2026-10-26-hoop-mode-design.md` (extends `docs/superpowers/specs/2026-10-23-lazerline-ar-design.md`)

## Global Constraints

- Pure modules (`src/hoop.js`, `src/settings.js`, `src/geometry.js`, `src/analysis.js`, `src/swing.js`) import no three.js and touch no DOM; vectors are plain `{x,y,z}`.
- `drill: 'line' | 'hoop'`, default `'line'`; invalid stored values fall back to `'line'`. Settings key stays `lazerline.settings.v2`.
- Tolerance is the existing `lineWidth` setting (2–30 cm, default 0.10 m): on if distance ≤ `lineWidth / 2`.
- Hoop radius `R = clubLength + 0.6` (m). Hoop lowest point = address clubhead.
- Hold: 3 s still; still = angular speed < 0.3 rad/s and clubhead within 0.03 m of where the hold began.
- Hoop address zone: virtual clubhead within 0.3 m horizontally of the address clubhead.
- Haptics: only while detector state is `'swinging'`, on each on → off transition, `pulse(0.6, 80)`, at most once per 250 ms, feature-detected.
- Colors: reuse `COLORS` (on `#22c55e`, off `#ef4444`, idle `#ffd400`, unsure `#9ca3af`).
- Prompts (exact): `'Take your address and pull the trigger.'`, `` `Hold still… ${n}` `` (n = 3, 2, 1), `'Pull the trigger to use this hoop. A to redo.'`, ready: `'Address the ball to start.\nThumbstick up/down: tolerance.'`
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; branch `build/lazerline-v1` (pushing it redeploys GitHub Pages).

## Review Focus

- **Shaft near vertical at address** (horizontal projection ~0): target direction must fall back to the provided right vector, never NaN. Pinned in Task 2.
- **Unsure (estimated) poses**: classify as `'skip'`; no buzz, no score. Pinned in Task 2 (classify) and Task 4 (buzz only on scored on→off).
- **Tracking lost during the hold**: countdown restarts; hoop never built from a missing pose. Task 4 step.
- **Untracked frame in ready**: hoop address predicate gets `null` → false, no throw. Pinned in Task 2.
- **Recalibration (B) after a hoop is accepted**: hoop kept, app returns to ready. Task 4 step.

### Task 2: Hoop math

**Files:** Create `src/hoop.js`, `tests/hoop.test.js`

**Interfaces:**
- `buildHoop(head: {x,y,z}, axis: {x,y,z} /* unit, toward clubhead */, radius: number, fallbackRight: {x,y,z}): Hoop`
  - `Hoop = { head, n, t, up, center, radius }` (all plain vectors; `n` unit plane normal, `t` unit horizontal target direction, `up` unit in-plane direction closest to world up).
  - `t = normalize(cross(UP, axisH))` with `axisH = {x: axis.x, y: 0, z: axis.z}`; if `|axisH| < 1e-3` use `normalize(fallbackRight with y = 0)`.
  - `n = normalize(cross(axis, t))`; `up = normalize(UP − n·(n·UP))`; `center = head + up·radius`.
- `planeDistance(p: {x,y,z}, hoop): number` — `|n · (p − head)|`.
- `classifyHoop(tip: {x,y,z} | null, unsure: boolean, hoop, tolerance: number): 'on'|'off'|'skip'` — `skip` if `unsure` or `!tip`; else `on` iff `planeDistance ≤ tolerance / 2`.
- `nearHoop(h: {x,z} | null, hoop): boolean` — `!!h` and horizontal distance from `hoop.head` < 0.3.

- [ ] **Step 1: Write failing tests in `tests/hoop.test.js`**
  - Address shaft lies in the plane: for `axis` at 60° from horizontal toward −z (e.g. `{x:0, y:-0.866, z:-0.5}`), `head = {x:0, y:0.02, z:0}`, `|n·axis| < 1e-9`, `|n·t| < 1e-9`, `|n.length − 1| < 1e-9`.
  - Lowest point is the head: `center − up·radius` equals `head` (each component within 1e-9) and `center.y > head.y`.
  - `t` is horizontal (`t.y === 0` within 1e-12) and perpendicular to `axisH`.
  - Vertical shaft `axis = {x:0,y:-1,z:0}` with `fallbackRight = {x:1,y:0.2,z:0}` → `t ≈ {x:1,y:0,z:0}`, no NaN anywhere in the hoop.
  - `planeDistance`: a point `head + n·0.04` → 0.04; `head + t·1 + up·0.5` → ~0.
  - `classifyHoop`: in-plane tip, tolerance 0.1 → `'on'`; tip at `n·0.06` → `'off'`; same tip with `unsure` → `'skip'`; `null` → `'skip'`.
  - `nearHoop`: `null` → false; `{x:0.2, z:0}` → true; `{x:0.4, z:0}` → false.
  - In-plane swing model: rotate a rigid club (pivot `head + up·R`, length R) about `n` from 0 to 4 rad; every tip classifies `'on'`. Same swing with the rotation axis tilted 10° off `n` produces at least one `'off'` at tolerance 0.1.

- [ ] **Step 4: Run `npm test`** — PASS.

### Task 4: Hoop drill wiring

**Files:** Modify `index.html`, `src/main.js`

**Interfaces consumed:** Task 1 `settings.drill`; Task 2 `buildHoop`, `classifyHoop`, `nearHoop`; Task 3 `view.setHoop`, `view.setTrail`.

- [ ] **Step 1: Start page** — a **Drill** fieldset (radios `name="drill"`: `line` "Line on the floor", `hoop` "Swing-plane hoop") above Mode; prefill from settings; `syncForm` saves `settings.drill`.
- [ ] **Step 2: State machine** — new `appState` values `'hoopAim' | 'hoopHold' | 'hoopConfirm'`; new vars `hoop = null`, `hoopAccepted = false`, `hold = null` (`{start: ms, tip0: {x,y,z}}`), `prevOn = true`, `lastBuzz = 0`. Leaving `'tune'` (trigger): Line drill unchanged; Hoop drill → `hoopAccepted ? 'ready' : 'hoopAim'`. Session start resets `hoop`, `hoopAccepted`.
  - `onSelect`: `'hoopAim'` → `'hoopHold'` with `hold = null` (begins on the next tracked frame); `'hoopHold'` → ignore; `'hoopConfirm'` → `hoopAccepted = true; appState = 'ready'`.
  - A (when not swinging): Hoop drill → `hoop = null; hoopAccepted = false; appState = 'hoopAim'; resetSwing()`; Line drill unchanged.
  - B: unchanged (goes to calibrate; leaving tune routes as above, so an accepted hoop is kept).
- [ ] **Step 3: Hold** (`'hoopHold'`, each frame): no pose → `hold = null`. Else compute the virtual clubhead `tip` (`clubEnds(...).head`) and angular speed from the previous frame's axis; if `!hold` start it; if speed ≥ 0.3 or `|tip − hold.tip0| > 0.03` restart it at now. Show `` `Hold still… ${Math.ceil(3 - elapsed)}` ``. At 3 s: `hoop = buildHoop(tip, axis, settings.clubLength + 0.6, cameraRight)` where `cameraRight` is `(1,0,0)` transformed by `camera.matrixWorld`; → `'hoopConfirm'`.
- [ ] **Step 4: Confirm** (`'hoopConfirm'`): show the hoop yellow, club stick visible, prompt `'Pull the trigger to use this hoop. A to redo.'`.
- [ ] **Step 5: Ready, Hoop drill** — hide line and floor lasers (`view.setLine(null)`, lasers null); stick visible. `state = classifyHoop(tip, unsure, hoop, settings.lineWidth)`; hoop color `unsure ? COLORS.unsure : COLORS[state]` (no hold-last: every tracked frame is scored; `skip` without `unsure` only happens with no pose, shown yellow). Sample: `head: tip && {x: tip.x, z: tip.z}`, `butt: null`, `tip: tip && {x,y,z copy}`. Detector for the hoop drill: a second `createSwingDetector({ addressNear: (h) => nearHoop(h, hoop) })` chosen by `settings.drill` (keep the Line detector untouched); `resetSwing()` resets both detectors. Haptics: if `detState === 'swinging'` and `prevOn && state === 'off'` and `now − lastBuzz ≥ 250`: `clubSrc.gamepad?.hapticActuators?.[0]?.pulse?.(0.6, 80)`; `lastBuzz = now`. Update `prevOn` only on scored frames (`state !== 'skip'`). Width flick unchanged (it is the tolerance). Ready prompt per drill (exact strings in Global Constraints). Trails/result/address clearing as in Line drill.
- [ ] **Step 6: Hoop visibility** — every frame outside `'ready'`: `view.setHoop(settings.drill === 'hoop' ? hoop : null, COLORS.skip)` (an existing hoop stays visible as a reference during recalibration; after A it is `null`). In Line drill the hoop is always hidden.
